## ⚠️ 重要说明

### 本项目必须编译后才能使用！

DeepSeek TUI 是一个 **Rust 项目**，不是直接运行的脚本或 Node.js 应用。

**关键特性**：
- ✅ 包含**两个独立的二进制文件**
- ✅ 必须从源代码**编译安装**
- ✅ 不能直接使用 `npm install` 或 `pip install`
- ✅ 修改源代码后**必须重新编译**

## 🚀 快速安装

### Windows 用户

```powershell
# 1. 安装 Rust（如果未安装）
# 访问 https://rustup.rs/ 下载 rustup-init.exe

# 2. 切换到项目目录
cd "F:\ai\codes\github\deepseektuizh"

# 3. 编译安装（必须执行）
cargo install --path crates/cli --locked --force
cargo install --path crates/tui --locked --force

# 4. 验证安装
deepseek --version
deepseek-tui --version
```

### macOS / Linux 用户

```bash
# 1. 安装 Rust（如果未安装）
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 2. 切换到项目目录
cd /path/to/deepseektuizh

# 3. 编译安装（必须执行）
cargo install --path crates/cli --locked --force
cargo install --path crates/tui --locked --force

# 4. 验证安装
deepseek --version
deepseek-tui --version
```

## 📖 详细安装步骤

### 步骤 1：安装 Rust 工具链

#### Windows

1. 访问 https://rustup.rs/
2. 下载 `rustup-init.exe`
3. 运行安装程序，选择默认选项
4. 重启终端

#### macOS / Linux

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source "$HOME/.cargo/env"
```

#### 验证 Rust 安装

```bash
rustc --version   # 应该显示 1.88 或更高版本
cargo --version   # 应该显示 1.88 或更高版本
```

```bash
git clone https://github.com/Hmbown/deepseektuizh.git

```

#### 方式二：下载 ZIP

```bash
# 解压后进入目录

```

### 步骤 3：编译安装（核心步骤）

⚠️ **这是必须的步骤，不能跳过！**

#### 为什么需要编译？

DeepSeek TUI 包含两个独立的二进制文件：

1. **`deepseek`** - CLI 调度器（主入口）
   - 处理命令路由
   - 管理配置
   - 启动 TUI 或其他子命令

2. **`deepseek-tui`** - TUI 运行时（交互界面）
   - 提供终端用户界面
   - 处理对话流
   - 显示思考和工具调用

**重要规则**：
- ✅ 必须**同时安装两个包**
- ✅ 修改 `crates/tui/` 下的代码后**必须重新安装 tui**
- ✅ 使用 `--force` 参数覆盖旧版本

#### 执行编译安装

```bash
# 安装 CLI 调度器
cargo install --path crates/cli --locked --force

# 安装 TUI 运行时
cargo install --path crates/tui --locked --force
```

#### 编译过程说明

- 📦 首次编译会下载依赖包（可能需要 5-15 分钟）
- 🔨 编译过程会占用较多 CPU
- 💾 安装位置：`~/.cargo/bin/`（Linux/macOS）或 `C:\Users\用户名\.cargo\bin\`（Windows）
- 🎯 生成的文件：`deepseek.exe` 和 `deepseek-tui.exe`（Windows）

## 🐛 常见问题

### Q1: 提示 "未找到命令: deepseek"

**原因**: 未安装或未添加到 PATH

**解决**:

```bash
# Windows PowerShell
$env:Path += ";$env:USERPROFILE\.cargo\bin"

# 永久添加（Windows）
# 将 %USERPROFILE%\.cargo\bin 添加到系统环境变量 PATH

# macOS / Linux
export PATH="$HOME/.cargo/bin:$PATH"
# 添加到 ~/.bashrc 或 ~/.zshrc
```

---

### Q2: 编译失败，提示 Rust 版本过低

**原因**: Rust 版本低于 1.88

**解决**:

```bash
# 更新 Rust
rustup update stable

# 验证版本
rustc --version  # 应该 >= 1.88
```

---

### Q3: 修改代码后没有生效

**原因**: 修改了源代码但没有重新编译

**解决**:

```bash
# 必须重新安装
cargo install --path crates/cli --locked --force
cargo install --path crates/tui --locked --force

# 特别提示：
# - 修改 crates/cli/ 下的代码 → 重新安装 cli
# - 修改 crates/tui/ 下的代码 → 重新安装 tui（必须）
# - 不确定 → 两个都重新安装
```

---

### Q4: 编译速度很慢

**优化建议**:

```bash
# 使用并行编译
cargo install --path crates/cli --locked --force --jobs 8

# 使用更快的链接器（Linux）
# 安装: sudo apt install mold
# 配置: 在 ~/.cargo/config.toml 添加:
# [target.x86_64-unknown-linux-gnu]
# linker = "clang"
# rustflags = ["-C", "link-arg=-fuse-ld=mold"]
```

---

### Q5: 磁盘空间不足

**清理编译缓存**:

```bash
# 清理旧编译产物
cargo clean

# 清理未使用的依赖
cargo install cargo-sweep
cargo sweep --installed
```

---

### Q6: Windows PowerShell 脚本无法执行

**解决**:

```powershell
# 以管理员身份运行
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 或临时绕过
PowerShell -ExecutionPolicy Bypass -File .\start-menu.ps1
```

## 🎓 进阶：从源码运行（不安装）

如果只是临时测试，可以不安装直接运行：

```bash
# 直接运行（不安装到全局）
cargo run --bin deepseek

# 带参数运行
cargo run --bin deepseek -- --provider openai

# 编译到 target/release/ 但不安装
cargo build --release
./target/release/deepseek
```

**注意**: 这种方式每次运行都会重新编译，速度较慢。建议正式使用还是执行 `cargo install`。
