# DeepSeek TUI 界面布局说明

> **版本**: 0.8.37  
> **更新日期**: 2026-05-16

---

## 📐 整体布局

DeepSeek TUI 采用**双栏布局**，左侧为主要对话区，右侧为任务面板：

```
┌──────────────────────────────────────┬──────────────────────────────┐
│         顶部状态栏 (Header)           │        Tasks (任务面板)      │
│  [Mode] [Model] [Cost] [Cache]      │  ┌──────────────────────┐   │
├──────────────────────────────────────┤  │  当前任务状态         │   │
│                                       │  │  后台作业列表         │   │
│                                       │  │  错误日志            │   │
│         主对话区 (Main)               │  │  活动日志            │   │
│         - 对话历史                     │  │  子代理状态          │   │
│         - AI 回复                     │  └──────────────────────┘   │
│         - 工具调用                     │                             │
│         - 思考过程                     │                             │
│                                       │                             │
│                                       │                             │
│                                       │                             │
├──────────────────────────────────────┤                             │
│         输入区 (Composer)             │                             │
│  > 在这里输入您的问题...              │                             │
│  [附加文件] [命令]                   │                             │
└──────────────────────────────────────┴──────────────────────────────┘
         左侧 (主区域)                           右侧 (Work/Tasks)
```

---

## 🎯 区域详解

### 1️⃣ 顶部状态栏 (Header)

显示当前会话的关键信息：

```
agent · qwen3.5-9b-deepseek-v4-flash@q6_k · Ctrl+O Activity: error  Cache: unavailable  worked 1m
```

**信息项**：
- **模式**: `agent` / `plan` / `yolo` - 当前工作模式
- **模型**: 正在使用的 AI 模型名称
- **活动状态**: 显示当前活动（如 `error`、`idle`、`working`）
- **缓存**: Token 缓存状态
- **工作时间**: 当前会话已工作时间

---

### 2️⃣ 主对话区 (Main Area) - 左侧

这是您与 AI 交互的主要区域，显示：

#### 对话历史
```
User: 请帮我写一个 Python 函数计算斐波那契数列

Assistant: 好的，我来为您编写：

```python
def fibonacci(n):
    """计算斐波那契数列的前 n 项"""
    if n <= 0:
        return []
    elif n == 1:
        return [0]
    
    fib = [0, 1]
    for i in range(2, n):
        fib.append(fib[i-1] + fib[i-2])
    return fib
```

这个函数使用迭代方法，时间复杂度 O(n)...
```

#### 工具调用显示
```
🔧 exec_shell
  Command: python test.py
  Status: ✓ Success
  Output: Hello World
```

#### 思考过程（Reasoning）
```
💭 Thinking...
  分析用户需求...
  确定最佳实现方案...
  编写代码...
```

---

### 3️⃣ 任务面板 (Tasks) - 右侧

显示当前会话的任务和后台活动：

#### 任务状态
```
┌ Tasks ──────────────────────────────────────────┐
│ turn 83778346-... (completed)                   │
│ No live tools or background jobs                │
│                                                  │
│ 学习本程序代码                                    │
│                                                  │
│ Note theme = dark (saved)                       │
│ Note theme = light (saved)                      │
└─────────────────────────────────────────────────┘
```

#### 显示内容
- **当前任务**: 正在执行的任务 ID 和状态
- **后台作业**: 运行中的子代理或工具
- **错误日志**: 最近发生的错误信息
- **活动记录**: 重要操作记录（如主题切换、配置更改）
- **子代理状态**: 并行运行的子任务

#### 任务状态标识
- ✅ `completed` - 任务已完成
- ⏳ `running` - 任务正在执行
- ❌ `failed` - 任务失败
- ⏸️ `paused` - 任务暂停

---

### 4️⃣ 输入区 (Composer) - 底部

用于输入消息和命令：

```
┌Composer──────────────────────────────────────────────────────────────┐
│                                                                       │
│ 编写任务或使用 /。                                                     │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

**功能**：
- 输入自然语言消息
- 使用 `@` 附加文件
- 使用 `/` 执行命令
- 多行输入（Shift+Enter 换行）

## 🎨 视觉元素

### 模式指示器

| 模式 | 显示 | 说明 |
|------|------|------|
| **Plan** | 🔍 `plan` | 只读调查，不修改文件 |
| **Agent** | 🤖 `agent` | 交互式，需要批准（默认） |
| **YOLO** | ⚡ `yolo` | 自动批准所有操作 |

### 状态图标

| 图标 | 含义 |
|------|------|
| 🔧 | 工具调用 |
| 💭 | 思考过程 |
| ✅ | 成功 |
| ❌ | 失败 |
| ⏳ | 进行中 |
| 📎 | 附加文件 |

### 错误显示

错误信息会在两个地方显示：

1. **主对话区**: 详细错误描述
2. **任务面板**: 错误摘要

```
Error Failed to send message: Refusing insecure base URL...
```

## ⌨️ 布局相关快捷键

| 快捷键 | 功能 |
|--------|------|
| `Tab` | 切换工作模式 |
| `Shift+Tab` | 切换推理深度 (off → high → max) |
| `Ctrl+O` | 打开/关闭任务面板 |
| `Ctrl+K` | 命令面板 |
| `Esc` | 取消/返回 |
| `/theme` | 切换主题 |

---

## 🎭 主题切换

不同主题会影响布局的视觉效果：

### 可用主题
- `light` - 浅色主题
- `dark` - 深色主题
- `gruvbox-dark` - Gruvbox 深色
- `tokyo-night` - 东京之夜

### 切换方法
```
/theme dark
/theme light
/theme gruvbox-dark
/theme tokyo-night
```

## 🔧 自定义布局

### 调整面板

目前布局是固定的，但您可以通过以下方式优化体验：

1. **终端大小**: 建议使用至少 120x40 的终端
2. **字体大小**: 调整终端字体以获得最佳可读性
3. **全屏模式**: 最大化终端窗口以显示更多内容

### 鼠标支持

如果启用了鼠标捕获（`mouse_capture = true`）：
- 可以用鼠标选择文本
- 点击按钮和链接
- 滚动查看历史

## 💡 使用技巧

### 1. 利用任务面板监控进度
- 查看后台任务状态
- 及时发现和处理错误
- 跟踪多个子代理的执行

### 2. 快捷键提高效率
- `Ctrl+O` 快速切换任务面板
- `/` 快速输入命令
- `@` 快速附加文件

### 3. 主题选择
- 白天使用浅色主题
- 夜晚使用深色主题减少眼睛疲劳
- 长时间工作推荐 `gruvbox-dark`
