# AICodeClaw 演示脚本
# 用于腾讯云 WorkBuddy 黑客松比赛

## 🎬 Demo 场景：代码审查与安全评分

### 前置准备

```bash
# 1. 启动本地模型（使用 Ollama）
ollama run qwen3.5:9b

# 2. 启动 AICodeClaw
./target/release/aicodclaw --model auto
```

### 场景 3：端到端工作流

```
# 1. 搜索相关信息
/web qianwen "推荐一个适合本地部署的 OCR 工具"

# 2. 列出可用工具
/tools list

# 3. 执行终端命令
/task shell_start 'cd crates/aiwebllm && ls'

# 4. 查看差异
/diff
```

### 场景 4：RLM 长文本分析

```
# 1. 打开日志文件
/rlm_open data/logs.txt

# 2. 搜索错误模式
/rlm_eval search pattern 'timeout'

# 3. 生成报告
/agent_close report.md
```
