## 📋 关键决策点

### 决策 1: Web API 逆向 vs 官方 API

**状态**: ⏳ 待决策

**选项**：
- **A. Web API 逆向**
  - ✅ 免费
  - ✅ 无需申请 API Key
  - ❌ 可能违反服务条款
  - ❌ API 变更频繁
  
- **B. 官方 API**
  - ✅ 稳定可靠
  - ✅ 官方支持
  - ❌ 可能有费用
  - ❌ 需要申请额度

**建议**: 先尝试 Web API 逆向验证可行性，如有问题再考虑官方 API

---

### 决策 2: 缓存相似度算法

**状态**: ⏳ 待决策

**选项**：
- **A. 关键词匹配**（简单快速）
  - ✅ 实现简单
  - ✅ 性能高
  - ❌ 准确率低
  
- **B. 语义相似度**（复杂准确）
  - ✅ 准确率高
  - ✅ 支持 paraphrase
  - ❌ 需要额外依赖
  - ❌ 性能较低

**建议**: 先用关键词匹配实现 MVP，后续可升级为语义相似度

---

### 决策 3: 会话持久化

**状态**: ⏳ 待决策

**选项**：
- **A. 内存会话**（简单）
  - ✅ 实现简单
  - ❌ 重启丢失
  
- **B. 磁盘持久化**（复杂）
  - ✅ 重启恢复
  - ❌ 需要序列化
  - ❌ 需要同步

**建议**: MVP 阶段仅内存，正式版支持可选持久化
