## 📋 整体设计规范

### 1. 配色方案（评审友好度提升）
| 元素 | 颜色 | HEX | 使用场景 |
|------|------|-----|----------|
| **主色** | 深蓝色 | #0D47A1 | 标题、核心能力图标 |
| **辅助色** | 青色渐变 | #42A5F5 → #1976D2 | Sub-agent 并行执行动画 |
| **强调色** | 绿色锁图标 | #4CAF50 | 私域化/零泄露证明 |
| **背景色** | 白色 | #FFFFFF | 正文、数据表格 |
| **文字色** | 深灰色 | #333333 | 正文内容 |

### 2. 字体规范（评审习惯）
| 位置 | 字体 | 字号 | 行距 |
|------|------|------|------|
| **主标题** | Microsoft YaHei Bold | 40pt | 1.3 |
| **副标题** | Microsoft YaHei Regular | 28pt | 1.3 |
| **正文** | Microsoft YaHei Light | 20pt | 1.5 |
| **代码块** | Consolas | 16pt | 1.2 |

### 3. 图标风格（技术感 + 私域化暗示）
- **Sub-agent**：三个重叠的蓝色圆形图标 → 体现"并行协作"
- **零泄露证明**：绿色锁形图标 🔓 → "开源"+"安全"
- **MCP 协议**：三条波浪线连接三个方块 → 体现"标准化协议"
- **Claw 抓取机制**：爪形箭头 + 数据流 → 直观表现"抓取能力"

## 🚀 PPT 制作工具建议（评审友好度）

### ✅ 推荐工具：PowerPoint（兼容性最好）
- **模板**：使用微软自带"商务科技"类模板（深蓝 + 青色渐变配色）
- **动画**："淡入"→"滑入"→"打字机效果"（避免复杂粒子动画，评审更关注内容）
- **导出格式**：`.pptx` + `.pdf`（PDF 便于评审在手机上查看）

### ❌ 不推荐工具：Canva/Prezi（评审可能不熟悉）
- 虽然视觉效果炫酷，但评审习惯看传统 PPT
- 避免过度设计，保持"技术感 + 私域化暗示"的核心定位
