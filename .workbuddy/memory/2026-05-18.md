3. **重构 `src/web_llm_client.rs`**
   - 添加 `DoubaoClient` 字段，支持延迟初始化
   - 新增 `new_doubao()` 便捷构造方法
   - `send_message()` 根据平台选择专用客户端或浏览器自动化降级方案
   - 提取 `get_send_button_js()` 和 `get_response_js()` 平台差异化方法
   - 针对千问/豆包使用不同的输入框选择器、发送按钮选择器、回复提取策略
   - 移除冗余调试代码和过时的选择器

### 关键优化点

| 方面 | 旧实现 | 新实现 |
|------|--------|--------|
| 选择器策略 | 通用 fallback | 平台差异化优先级链 |
| 稳定性检测 | 无或固定超时 | 连续 N 次内容不变 |
| 重试机制 | 无 | 自动重试 N 次 |
| 输入方式 | 仅 type_into | JS 直接操作 DOM（更可靠） |
| 弹窗处理 | 简单关闭 | 多种弹窗自动关闭 |
| 配置化 | 硬编码 | DoubaoConfig 可配置 |
| 调试输出 | 分散且过多 | 清晰的结构化日志 |
